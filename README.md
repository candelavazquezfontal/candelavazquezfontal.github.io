# Web personal de Candela Vázquez Fontal

Sitio estático publicado con GitHub Pages.

- `index.html`: toda la web (inicio, trayectoria, proyectos, certificaciones y contacto).
- `certificados/`: certificados en PDF enlazados desde la sección de certificaciones.

## Cómo actualizarla

Los datos están al final de `index.html`, en dos listas:

- `CERTS`: una línea por certificación (título, emisor, categoría, fecha y enlace).
- `PROJECTS`: un bloque por proyecto (problema, qué se hizo, mi parte, resultados, herramientas y enlace).

Edita el archivo en GitHub (icono del lápiz), guarda con "Commit changes" y la web se actualiza sola en unos minutos.
